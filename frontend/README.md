# Fix-My-Ride Frontend

This directory will contain the React frontend application for **Fix-My-Ride**.

## Current Status

This folder is currently a placeholder created during **Phase 1 — Foundation (Commit 01 — Project Skeleton)**. No frontend code or packages have been added yet.

## Planned Technologies

The following frontend technologies will be introduced in subsequent commits:

- **React** (with JavaScript) for building the user interface
- **Vite** for fast local development and bundling
- **Material UI (MUI)** for pre-built UI components
- **Axios** for communicating with the backend API
- **CSS** for custom styling
